Park 给的参考图，只记录不代表已采纳；每张写清「他看中的是什么」。

## floating-tabbar-reference.png（2026-09-30，Park）

Park 原话：「我觉得下面这个 bar 好像更好看，更有现代感一点。先记录一下，下次再改，现在先不需要改。」

他看中的是底部导航的形态：**悬浮胶囊**——不是贴底通栏，而是离底边有间距、圆角很大的一条，浮在内容之上；图标加文字横排、当前项用浅色药丸底衬托，右侧另有一个独立的圆形主按钮。整体更轻、更现代。

轻练现在是自定义 tabBar（`apps/miniprogram/custom-tab-bar/`），贴底通栏，三项：今天 / 计划 / 我的。改法和风险见 issue #49。
