# 客户入口与教练工作台分离

**Status: accepted（2026-09-14 修订落点）**

微信小程序的客户 API 与教练私有工作台是两个不同的权限边界；私有工作台不能直接充当客户入口。这样可以让教练内容管理继续保持私有，同时为微信登录、客户只读发布版本和客户提交反馈建立独立的访问契约。

## 修订：两个权限边界落在同一个云函数内（2026-09-14）

小程序 `wx.request` 的服务器域名必须经过 ICP 备案，体验版真机同样校验；独立客户 API 域名在备案前不可用。首客试点改为客户与教练都通过 `wx.cloud.callFunction` 进入同一云函数，身份取自平台注入的 OPENID。

权限分离的原意保留并收紧：客户操作只能触达本人数据、只返回已发布版本；教练操作要求 OPENID 位于教练白名单。两类授权在函数内分别检查，请求体中的任何身份字段均被忽略。私有 Sites 网页保留为演示与设计沙盒，不在试点数据链路上。
